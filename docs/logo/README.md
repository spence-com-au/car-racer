# Logo

A yellow kart drifting past a chequered flag, trailed by six speed streaks in six of the player
colours (the Okabe-Ito hues in `CarColours`). The wordmark is Inter Display Black Italic,
outlined to paths so it renders the same everywhere.

| File | Use |
| --- | --- |
| `icon.svg`, `icon-rounded-512.png` | App icon with rounded corners: store listings, docs, social |
| `icon-square.svg`, `icon-512.png` | Full-bleed icon for Android, which masks it to the launcher's shape |
| `logo.svg`, `logo.png` | Icon and wordmark on light backgrounds |
| `logo-dark.svg`, `logo-dark.png` | Icon and wordmark on dark backgrounds |

The SVGs are the sources; the PNGs are renders of them.
